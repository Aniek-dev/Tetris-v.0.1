# 🕹️ Tetris Clásico en HTML, CSS y JavaScript

¡Bienvenido a mi versión del clásico juego Tetris! Este proyecto está desarrollado únicamente con HTML, CSS y JavaScript, y es una implementación sencilla y funcional del icónico juego de rompecabezas.

## Características

- Juego de Tetris clásico con diferentes tipos de piezas
- Control con teclado:
  - Flechas para mover y rotar las piezas
  - **Tecla C** para hacer hold (guardar la pieza actual y usarla más tarde)
- Detección y eliminación de líneas completas
- Animación de un cassette que reproduce la canción de Tetris

## 🚀 Cómo jugar

1. Puede clonar o descarga este repositorio.
2. Tambien puede hacer clic en el siguiente enlace que esta abajo.
3. Usa las teclas del teclado para jugar:
   - 🡸 	 : mover a la izquierda
   - 🡺: mover a la derecha
   - 🡻 : acelerar la caída
   - 🡹 : rotar la pieza
   - **Tecla C**: hacer hold (guardar la pieza actual y usar la guardada)
4. Intenta completar líneas completas para eliminarlas y obtener puntos.


## Cómo usar

- Para reiniciar el juego, simplemente actualiza la página

## 🎵 Animación y música

- Se incluye una animación de un cassette que reproduce la canción de Tetris mientras juegas.
- La canción se inicia al clickear play y acompaña la partida para crear un ambiente retro.


  
## 🛠️  Tecnologías utilizadas

- **HTML5** para la estructura del juego
- **CSS3** para el estilo, la animación del cassette y la presentación
- **JavaScript** para la lógica del juego y la interacción
